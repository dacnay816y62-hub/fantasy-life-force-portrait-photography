# 胶片模式｜可直接组装的提示词

先按 [模式规范](film-mode.md) 选择任务与配方。方括号是需要按当前任务填写的变量，提交给图像工具前替换。不要只写胶片品牌、“film aesthetic”或一串相机型号。

## 1. 原片编辑模板

```text
编辑所提供的原照片。保留原人物身份、年龄、五官比例、表情、动作、体型、服装、发型、物体关系、原构图和画面比例；不替换场景，不新增妆容、雀斑或痣。

应用 Fantasy 胶片模式：[配方名称]，[轻/标准/浓]。根据原照片的[主光方向与软硬]，把亮面到高光的过渡变得柔和，保持[黑发/深色衣物/暗部家具]的深色密度；[明确中间调亮度]。白色为[中性/奶油白/冷白]，肤色保留本人自然颜色和局部血色，环境[绿/蓝/木色]按场景分别调整，不做全图黄染。

加入[细弱/细至中细、可见/明显而细密]的不规则有机颗粒；颗粒属于整个成像，皮肤、布料、天空、墙面质感统一，在不同明暗中自然显隐。保留原有皮肤纹理，不增加雀斑、不形成彩噪或砂砾。若原片已有明显颗粒，不重复叠加。

只在[原片确有的亮源与位置]增加[极轻 bloom / 有依据的局部 flare]；若没有对应光源，关闭光晕。默认无明显 halation、无 RGB 色散、无旋焦。自然镜头解析、轻柔微反差，眼睛、嘴唇与手部结构清楚；不全图模糊、不锐化出白边。

交付一张独立照片；不添加边框、日期戳、字幕或水印。
```

## 2. 原创生成模板

```text
生成一张原创生活人像：[人物与年龄]正在[具体动作或安静停顿]，地点是[与事件有关的真实场景]。人物松弛、具体、自然，穿[适合事件的衣服]；镜头像熟悉的人在[机位与距离]拍下这一刻。使用原创人物，不照搬风格参考的人物、衣服、道具与构图组合。

Fantasy 胶片模式：[配方名称]，[强度]。[光向、光比和空间层次]。[用一两句描述该配方的中间调、柔高光、黑位与肤色/环境色]。

[颗粒的细度、强度与全幅一致性]。自然镜头解析、柔和微反差，保留真实皮肤、飞丝与衣料。[仅在有光源依据时写局部 bloom、halation 或 flare 的位置和强度；否则明确关闭]。让摄影事件与成像共同成立，不靠划痕、漏光或泛黄表达怀旧。

[数量和比例]，独立照片；无拼图、无边框、无新增文字水印。
```

## 3. 八个质感段落

任选一个插入主提示词，不要把八个全部叠加。

### F01 温润日常

> 温润的日常彩色负片扫描观感，暖米白与木色，米桃肤色，环境暗部略带橄榄或蓝灰，保留黑发和深色物体的密度。红色点缀可浓郁，整体不黄不灰。中细颗粒轻而可见，亮部柔和收束，窗沿或白布只在真实受光处有极轻柔溢；无额外太阳光斑。

### F02 晴日空气

> 日光通透，奶油白、柔和青蓝和自然日晒肤色，阳光面明亮，阴影仍有体积，黑发不是灰色。白衣褶皱和云层保留轻柔层次，细密颗粒在天空和中间调自然可见。少量亮部 bloom，只在真实逆光条件下出现微弱 flare；不把整幅漂成白雾。

### F03 室内颗粒

> 熟人视角的室内彩色胶片快照，暖肤与青绿、蓝灰室内环境形成克制冷暖关系，中间调略收，头发和家具维持浓黑。明显而细密、不规则的有机颗粒覆盖整个成像，皮肤结构与颗粒彼此区分。柔和微反差、清楚的眼神和自然笑纹，没有新增雀斑、彩色噪点、强光晕或泛黄滤镜。

### F04 暖光逆照

> 真实逆光使发丝、薄布和窗沿透亮，暖高光与相对冷的阴影分离，最深黑色保持重量。光源附近局部柔溢和有方向的光幕，向远离光源的区域逐渐减弱；只有极亮边缘可有很轻暖色回晕，不做橙色描边。中细颗粒清晰可感，面部亮暗仍有体积，五官不被光吃掉。

### F05 浓影硬光

> 日光与深影分区明确，暖亮面、深木色和蓝灰阴影，大光比但高光顶端柔和。保留深色背景，不做 HDR 阴影抬升；面部关键结构可辨。全幅明显而细密的颗粒与柔和镜头解析，局部光斑可以亮，但不形成没有纹理的整块皮肤；无无来源眩光。

### F06 森林绿

> 深叶绿、橄榄绿与阳光下黄绿叶片有层次，米桃或自然暖棕肤色独立于绿色环境，纸张和布料偏温润中性。阴影有深度，日光只温暖局部受光面。细至中细颗粒、自然镜头微反差与克制亮部柔溢，不把植物拉成荧光绿，不把脸染成黄绿，不强加漏光。

### F07 家庭相册

> 温暖而鲜活的家庭相册观感，真实室内光或户外日光，红蓝点色明确，白色和肤色仍自然。中等对比，略柔的镜头细节，细颗粒统一遍布画面。人物姿态、表情和服装符合年龄与活动；生活中的小失衡保留，不套时装大片妆容、不加怀旧棕滤镜或人为划痕。

### F08 清透微颗粒

> 清淡、自然的胶片色彩模拟，保留皮肤真实颜色、眼神与飞丝，绿或蓝背景干净分层，亮部略柔，黑发有细节。只有非常细弱的颗粒，不降低整幅清晰度，不追加眩光、暖边或 RGB 色散。原片若有玻璃反射，保持真实平面与方向；没有玻璃就不添加叠影。

## 4. 两个完整使用例

### 同一人物的三张咖啡馆组照

用户请求：`生成 3 张同一个成年女性在咖啡馆的胶片组照，温润自然。`

执行：D-create，F01 标准；先确定一位原创成年女性和同一身基础衣服，三张始终保持身份、年龄、发型与服装连续。第一张在吧台取杯，第二张坐下翻开随身小册子，第三张听同行者说话时轻笑。围绕同一扇窗的侧光，分别用环境中景、侧面近景和脸手同框；保持暖米白、木色、冷灰暗部与中细颗粒，不强制色散。输出 3 张独立 3:4，不能把人物差异规则解释为每张换脸。用户另有年龄、数量、比例或场景要求时跟随其要求。

### 阴天手机原片，仅增加明显颗粒

用户请求：`保留这张阴天自拍，只增加明显胶片颗粒，不要发黄。`

执行：D-edit；保留构图、曝光、色温、人物和场景。细至中细有机颗粒全幅一致、可见度提高，保留皮肤原有纹理；不叠雀斑，不改变妆容，不新增太阳、暖色 flare 或红边，不擅自改成 F04。若原片已有强数字噪声，先整理明显彩斑，再保持同等清楚的五官和细密颗粒观感。交付原比例的一张独立照片。

## 5. 按症状纠偏

| 结果问题 | 追加修正 |
| --- | --- |
| 看起来只是数字照片加噪点 | 保留细粒，补写中间调密度、柔高光、黑位、分区配色和微反差；不要单纯加大噪点 |
| 肤色变脏黄或灰绿 | 恢复个人自然肤色与中性白；只在环境暗部保留轻微色偏 |
| 全幅灰雾、黑发变灰 | 恢复最深黑位与中间调对比；将光幕限制于真实光源附近 |
| 脸上新增雀斑 | 移除新增皮肤斑点；颗粒是全幅成像结构，不是脸上的装饰 |
| 亮部吞掉眼鼻口 | 收回面部 bloom 和曝光，保留窗外/太阳自身的亮白 |
| 没有太阳却出现光斑 | 关闭 flare 与 halation，只保留曲线、颗粒和原光线 |
| 噪点又大又彩 | 降粒径，减彩噪，改成细密、不规则、亮度主导的质感 |
| 一组每张像不同滤镜 | 固定主配方、白色倾向、肤色和颗粒尺度，仅允许照明造成的自然变化 |

负面约束按任务挑选：塑料皮肤、噪点砂砾、彩色脏斑、HDR 光边、全幅泛黄、均匀灰雾、面部过曝、无来源光斑、全轮廓橙边、全屏 RGB 色散、无要求的日期戳与水印。不要复制原 MODE B 的“禁止普通生活抓拍 / 禁止重颗粒”等冲突词。
