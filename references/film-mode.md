# MODE D｜胶片模式

按光线和人物状态选择一种胶片观感，再写颗粒、明暗曲线、色彩、局部光学反应与扫描锐度。目标是有日常温度和物质感的照片；不是把数字图统一染黄、加噪点或铺雾。

这里是视觉模拟规范，不是胶片鉴定或扫描仪标定。参考是已处理的网络图像，无法据此确定真实胶片品牌、ISO、镜头、曝光或冲扫流程。参数是提示词的相对强度，不是相机参数或软件滑杆值。

需要理解来源时读 [逐图分析](film-reference-analysis.md)；需要直接组装提示词时读 [提示词模板](film-prompts.md)。本文件不依赖原始参考图片存在。

## 1. 先确定任务和输入角色

| 用户输入 | 执行方式 |
| --- | --- |
| 原照片＋“胶片模式 / 胶片感 / film look” | D-edit：保留身份、年龄、五官、表情、动作、服装、物体关系、原构图与场景；只处理影调、色彩、颗粒和合理局部光学反应。用户另有编辑要求时按要求扩展 |
| 只有主题＋“胶片模式” | D-create：原创人物和事件，允许朴素衣服、安静表情、环境远景与生活抓拍；不继承 MODE B 的强色散、强造型和高饱和要求 |
| 人物原片＋另一组质感参考 | 前者作为身份与结构输入，后者只提取影调、光色、颗粒和镜头关系；不要用参考人物替换原片人物 |
| 只有风格参考＋“分析 / 升级 skill” | 分析或更新规则；不要擅自重绘这些图片或调用生图服务 |
| “A / B / C＋胶片” | A/B/C 决定保留什么、创作什么；D 决定最终成像质感。具体编辑边界以用户要求为准 |

如果只有一张图片、用户说“改这张”，它就是原片。不要误当风格参考而重新设计人物。只有真正无法区分原片与参考时才询问。

用户只说“胶片模式”而没有指定类型：选最接近原片光线的一个配方，强度为“标准”。不要求用户先选胶片品牌。没有提到胶片的 A/B/C 请求保持原行为。

## 2. 与原模式的衔接

这些替代仅在 D 激活时生效，不全局更改 A/B/C。

| 原有规则 | D 的替代规则 |
| --- | --- |
| 高饱和、高对比、暗部打开 | 按配方建立曲线；可柔和、也可浓影；黑发和暗部保留深度，不一律抬灰 |
| 明确色散、一主一辅镜头异常 | 默认关闭 RGB 色散和旋焦；可以没有附加光效。颗粒、曲线、色彩是成像基础，不算堆特效 |
| 禁止重颗粒、普通生活抓拍 | 允许可见且细密的有机颗粒、熟人视角与安静的生活瞬间；仍避免脏点、彩噪和过度摆拍 |
| 面部一律明亮哑光、回避重阴影 | 允许自然侧光、局部明亮受光面和环境阴影；保留脸部体积，不磨平或涂油，不以过曝掩盖五官 |
| 服装必须有设计感、必须有妆容 | 基础衬衫、针织、家居衣服与素颜都可成立；编辑保留原妆容和衣服，不追加统一腮红或雀斑 |
| 近景占固定比例、动作要明显 | 景别围绕事件；环境远景、低头、停顿和眼神交流可成立；不强制歪机位或大笑 |
| 批量每张换脸、换场景 | 先判断同一人物的连续故事还是不同人物样片；前者锁定人物、穿着和主要色彩，变化景别与时刻 |
| 整批禁止拼图 | 默认独立图；参考拼图不改变输出格式。只有用户明确要求才拼图或加边框 |

编辑原片不执行“改变参考五个维度”或“改变五官三项”。原创时从参考中提取摄影规律，并重新建立人物、事件和画面；不照搬某一幅的整套内容。同一人物组照不执行换脸规则。

## 3. 胶片成像的六层控制

### 3.1 有机颗粒：可感知，但不变成一层脏点

- 默认描述为细至中细、大小略有变化、无方向性、非周期的染料云团般颗粒。避免均匀网点、像素噪声和粗大的黑白砂砾。
- 颗粒覆盖整幅成像：皮肤、头发、墙面、天空和布料都处于同一种质感中。不能只在皮肤上画点，也不能让脸成为被磨平的无颗粒孤岛。
- 本模式追求的观感：中间调与暗部中的颗粒较易察觉，平滑天空也可能看得见；亮部保留更轻的颗粒，近纯白区自然减弱。它不是“暗部越黑噪点越多”的固定公式。
- 以亮度变化为主，色彩颗粒克制。避免红绿蓝彩色脏斑、热像素、JPEG 方块、条带与摩尔纹。
- 颗粒和皮肤结构分开处理：保留原有毛孔、痣与雀斑；不得把参考中的雀斑迁移到用户脸上。
- 若原图已有明显颗粒或噪声，先评估是否需要整理，避免继续叠加。不要先磨皮，再用噪声补“真实感”。
- 同时检查最终展示尺寸和 100% 视图：缩图可感到细密材质，放大仍有五官、发丝和织物结构。输出更大时不要直接放大成粗点。

### 3.2 影调曲线：软高光与有密度的暗部

- 中间调承担肤色与身体体积；亮面到高光缓缓过渡（soft highlight shoulder），避免数字式白色断层。
- 允许太阳、窗外、水面反光、极亮布边局部接近白色；不要为了“胶片”把脸、白衣和天空一起剪平。
- 黑位和阴影分别处理：可给阴影轻微柔化，同时保留黑发、家具、暗门内等最深的锚点。低反差不等于整幅泛灰。
- 阴影可有克制的青、绿或蓝倾向；肤色不跟着变青灰或芥末黄。高反差配方可保留大面积深影，不强做 HDR 提亮。
- 晴日配方可以亮，室内配方可以暗；“增加高光”应先明确是亮部过渡、明亮受光面、bloom 还是 flare，而非直接抬高整张曝光。

### 3.3 光晕：区分三种现象

| 现象 | 可见表现 | 开启条件与边界 |
| --- | --- | --- |
| Bloom / 亮部柔溢 | 白布、窗沿、水面反光附近柔软的亮度扩散 | 随亮源局部发生，保留非亮区清晰度；默认微弱，不对全画面高斯模糊 |
| Halation / 胶片式暖边 | 极亮边缘外侧窄而克制的暖红、琥珀色回晕 | 只在高反差亮暗交界试用，默认关闭或极轻；不是每种胶片都必须明显，也不是全轮廓橙色描边 |
| Lens flare / 镜头眩光 | 有方向的低反差光幕、局部鬼影或光斑 | 明确逆光、画内/画边强光源才启用；图 5、6 的大范围亮幕优先按 flare 分析，不能全叫 halation |

- 从原片可以解释的光线出发；阴天、漫射树荫和没有强逆光的室内不凭空生成太阳光斑。
- 同一张可以没有任何明显光晕。若要加强，选一个有依据的主要光学反应，其他保持极轻或关闭。
- 温暖亮面不等于油亮皮肤。自然阳光可以照亮鼻梁、面颊和肩部，但不造镜面白条、不覆盖主要眼神和嘴唇。

### 3.4 色彩：以场景分区，保留肤色

- 肤色优先为米桃色、淡杏色或自然暖棕色，保留个体肤色、红润区域和冷暖差；不统一漂白。
- 白色可略带奶油、暖灰或清淡冷白，但画面仍要有接近中性的参照，避免所有白物发黄。
- 绿可偏橄榄、叶绿或柔和蓝绿；阴影叶片与透光叶片应有区别，不把所有树都拉成荧光绿。
- 蓝天与海面可偏柔和青蓝；浓影配方可用更深蓝灰。不要一律青橙分离。
- 红、番茄色、针织花纹、木色可以浓郁，允许鲜活；控制的是相互关系，而非全局去饱和。
- 同一组锁定一个主要配方，允许曝光随地点变化；不要每张随机换一种滤镜。

### 3.5 镜头与扫描观感：柔而有结构

- 自然镜头解析和轻柔微反差，减少数字锐化光边；眼睛可清楚，皮肤和头发不必根根锐利。
- 允许真实景深、轻微焦点偏移、风动发丝或动作边缘模糊，不能用全图糊掩盖生成问题。
- 近距离亲密感不等于超广角大鼻子。构图可参考 35–50mm 的自然视角；这是创作选择，非从参考推断器材。
- 扫描感不自动包含灰尘、划痕、漏光、日期戳、齿孔和胶片边框；这些只有用户提出时才加入。
- 玻璃反射须有玻璃平面、方向和明暗关系；不能把图 14 的反射误做成人脸重影或任意双重曝光。

### 3.6 生活状态：质感服务于这一刻

可以是接过一只杯子、停下来看窗外、对熟人笑一下、整理衣角或两人安静并肩。保留小范围失衡、真实物品和环境尺度。不要为了“生命感”强制改成大笑、奔跑、鲜花前景或复杂造型。

## 4. 八个可调用配方

下面的 0–4 是内部视觉强度：0 关闭，1 轻，2 可见，3 明显，4 强。每个数字必须翻译成自然语言后才用于图像工具；不是任何 API 的已支持参数。不要把 4 当作满屏效果。

| ID / 名称 | 适合与来源 | 曲线与色彩 | 颗粒 G | Bloom B | Halation H | Flare F |
| --- | --- | --- | --- | --- | --- | --- |
| F01 温润日常 | 厨房、咖啡馆、窗边；图 1、20 | 米白、木色、自然暖肤；轻橄榄/蓝灰暗部，红色局部保浓；黑发有密度 | 2 | 1 | 0 | 0 |
| F02 晴日空气 | 户外走动、海边、明亮白墙；图 2、8、9、15 | 高明度、奶油白、柔青蓝，日晒肤色；白物柔亮，阴影仍有体积 | 2 | 2 | 0–1 | 0–1 |
| F03 室内颗粒 | 车内、沙发、室内近照；图 3、11 | 中间调略收，暖肤与青绿/蓝灰环境；保留浓黑，不额外压暗脸 | 3 | 0–1 | 0 | 0 |
| F04 暖光逆照 | 逆光旅行、窗边关系照；图 5、6、16、19 | 暖亮部、相对冷的暗部，保持正常或浓郁黑位；让光源附近局部退反差 | 2–3 | 2 | 1 | 1–3，仅有依据时 |
| F05 浓影硬光 | 木门、斑驳日光；图 10 | 大光比，暖亮面＋蓝灰深影，柔化高光顶端；拒绝平均提亮 | 3 | 1 | 0–1 | 0 |
| F06 森林绿 | 草地、树荫、乡间；图 12、17/18 | 深叶绿＋黄绿透光叶，米桃肤色与木/土色；阳光局部温暖，阴影有深度 | 2 | 1 | 0 | 0–1 |
| F07 家庭相册 | 家庭活动、儿童日常；图 4 | 温暖白色和明确红蓝点色，朴素光线、中等对比；不统一怀旧棕 | 2 | 1 | 0 | 0 |
| F08 清透微颗粒 | 树荫近照、花间侧光、海边玻璃；图 7、13、14 | 自然肤色、清淡暖亮部、清洁绿/蓝背景；保留细节，少退色 | 1 | 0–1 | 0 | 0 |

范围值由真实光线决定。F02 没有入射强光时 F=0；F04 室内窗边无需强眩光时 F=0–1；F08 图 14 的反射属于场景结构而非 F。森林和室内配方均不强制漏光。

### 强度与细调

- **轻**：颗粒弱一档、色偏更淡、微反差更接近原片，光晕关闭或极轻。
- **标准**：按所选配方；这是默认值。
- **浓**：颗粒或色彩密度加强一档，最高 4；仍保持脸部结构、最深黑位和合理白色。不要同时加黄、加雾、加光晕、降清晰。
- **单独加颗粒**：只调 G；**高光更柔**：调过渡与 B；**日晒更亮**：小幅改变受光面和中间调；**保留黑位**：不抬最深黑色；**无光晕**：B/H/F 均关闭。用户可以独立组合。
- 用户指定“无颗粒胶片色彩”时 G=0，保留曲线与配色，不反过来强加颗粒。
- 用户指定真实胶片品牌时，作为审美方向，并描述预期可见特征；不声称精确还原化学成像。

## 5. 执行顺序与拍摄卡

1. 分辨原片、风格参考和原创主题；确定编辑/生成/提示词任务。
2. 识别主光方向、光比、已有曝光与颗粒、肤色、关键深色与白色物体。
3. 选择一个配方与强度，把身份和结构保护项写在提示词前面。
4. 写中间调与高光过渡，再写局部配色、颗粒、扫描微反差；仅加入可解释的光晕。
5. 按当前可用图像工具及其真实参数执行。若用户只要提示词或分析，只交付对应文本。
6. 按下面质检局部修正；一次纠正最明显的问题，避免不断叠滤镜。

```text
任务：D-edit / D-create；或 A/B/C＋D
输入角色：原片 / 风格参考 / 主题
保持项：人物、年龄、五官、表情、动作、衣服、场景、构图；按用户要求调整
人物与事件：具体正在发生的一刻
配方与强度：F01–F08；轻 / 标准 / 浓
光源依据：方向、软硬、亮源是否入镜、已有反射
影调：中间调、柔高光、最深黑位、可接受的局部亮白区
色彩：肤色、白物、绿/蓝、关键点色分别处理
颗粒：细度、强度、随明暗的可见度、原图是否已有颗粒
光学：B/H/F 的开关、位置和程度；不需要则全部关
锐度：自然解析、轻柔微反差，五官与原有细节可辨
系列：同人物连续 / 不同人物样片；锁定一个主配方
交付：用户数量与比例；编辑默认保留原比例，原创未指定时独立 3:4
```

同一人物的三到五张组照可穿插环境、互动、近景、物件细节，但不是固定张数要求。不要把参考中的拼版直接当输出模板。

## 6. 胶片模式专属质检

| 检查 | 通过条件 | 常见修正 |
| --- | --- | --- |
| 保真 | 编辑的身份、年龄、姿态与物体关系保持；同人组照身份连续 | 去掉无关的重设计语句，强调原片保护项 |
| 颗粒 | 全图共享细密、不规则质感，脸上没有新长的雀斑和彩斑 | 减弱粒径和彩噪，不靠磨皮清除所有细节 |
| 高光 | 白物有柔过渡，主要面部结构仍可辨 | 收回面部溢出，保留亮源自身的亮白 |
| 暗部 | 有深度和层次；没有全幅灰膜，也没有无理由压黑脸 | 分开处理最深黑位与可读阴影 |
| 光晕 | 位置、方向、强度由光源解释；无光源时允许没有 | 关闭无依据的 H/F，缩小 B 的影响范围 |
| 色彩 | 肤色自然，白色不全面泛黄，绿蓝有层次 | 局部色彩调整；减少全局黄/青染色 |
| 清晰度 | 眼神、嘴唇、手部结构可辨，无数字锐化白边 | 减微反差而不全图模糊；保留真实焦点 |
| 生活感 | 可感到人物与环境的关系，安静或热闹都成立 | 删掉不必要的摆拍道具和强制笑容 |
| 交付 | 数量、比例、组照连续性正确；参考水印和文字未被照搬 | 默认独立图，不因参考是拼图而合成 |

交付时简短注明所选配方和处理重点。将数值卡留在过程稿；不向用户声称完成了实测冲扫模拟、RAW 调色或逐像素保真，除非确实执行并验证过。
